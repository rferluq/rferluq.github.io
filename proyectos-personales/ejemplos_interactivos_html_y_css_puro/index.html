Laboratorio HTML & CSS Puro

Cuatro técnicas interactivas modernas sin una sola línea de JavaScript.

Ejemplo 01 · Selector Relacional

Modo Oscuro / Claro con :has()

El selector padre body:has(#modo:checked) detecta si el <input type="checkbox" id="modo"> de la cabecera está marcado y actualiza automáticamente las variables CSS de toda la página con transiciones suaves.

Ejemplo 02 · Pseudo-clase de Ancla

Zoom de imagen con :target

Al pulsar la miniatura envuelta en <a href="#imagen1">, la URL apunta al identificador #imagen1 y activa la regla #imagen1:target, animando la opacidad y escala (transform: scale(1)) del visor modal.

Ejemplo 03 · Animación Continua

Carrusel infinito con @keyframes

Un contenedor con overflow: hidden aloja una pista duplicada que se desplaza de 0% a -50% mediante animation: desplazamiento 14s linear infinite. Pasa el cursor por encima para pausarla con :hover.

Ejemplo 04 · HTML Nativo

Ventana flotante con popovertarget

El atributo HTML popovertarget="info-popover" abre y cierra un contenedor con atributo popover en la capa superior del navegador, permitiendo estilizar su fondo con el pseudo-elemento ::backdrop.

Ampliada mediante #imagen1:target Cerrar ✕

✨ Popover HTML Nativo

Esta ventana flota sobre todo el contenido usando la API nativa popover. Puedes cerrarla pulsando la tecla Esc, haciendo clic fuera sobre su ::backdrop o pulsando el botón inferior con popovertargetaction="hide".
